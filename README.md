A one-page newspaper summing up Friday 20 November 2026 in 50 verified stories:
4 big illustrated stories, 12 medium illustrated stories, 34 more in a list, a
world map with 20 pins, a UTC timeline strip (overnight → morning → noon →
afternoon → evening) and a DATE CHECK box listing the stories left out on
purpose because they broke on an earlier day.

Every story on the page happened, or was first reported, on Friday
20 November 2026. Each carries its source and a CLAIM/CONFIRMED label.
All illustrations are original drawings.

## Run it

```sh
node shot.mjs            # renders page.html to entry.png (1024x1024)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # copies entry.png to out/
```

Built by an AI agent for make.fun's "Sum up 20 November's world news in one
image" bounty.
